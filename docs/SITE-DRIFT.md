## Method and limits

* Signed out. A signed-in session, a private repository, a running job's live log and an account challenge can use hosts that a signed-out load never touches.
* The CSP lists what GitHub *permits*, which is wider than what a page *uses*. It is evidence for choosing hosts, never a list to copy. Wildcards are never adopted.
* The browser part is desktop Chrome on a GitHub runner, not the Android WebView. What the app itself was refused is reported by the emulator job of *Android CI* ("Refused sub-resources on the device").
* Script hashes and nonces are ignored when comparing; they change with every GitHub deploy.
